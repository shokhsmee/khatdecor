POS Login Screen Custom Background
This module allows you to customize the POS login screen by setting a background image directly from Point of Sale settings. Users can easily upload an image and instantly preview it as a thumbnail within the settings interface.
The selected background is dynamically applied to the POS login screen using a lightweight frontend extension, ensuring seamless integration without impacting core functionality or performance.
