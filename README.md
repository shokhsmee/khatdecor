# Khatdecor — Odoo 19 custom addons

Custom modules of the Khatdecor (ex-Kerama) Odoo 19 Enterprise deployment.

| Module | Summary |
|---|---|
| `chatter_toggle` | Toggle button to show/hide the Chatter panel in all form views |
| `cst_direct_login_pos` | Allow users to log in directly to the POS screen without accessing the backend. |
| `cst_kerama_ai_voice` | Speak to the MuK AI assistant: a microphone in the chat composer that turns Uzbek, Russian or English speech into text. |
| `cst_kerama_appsbar` | Collapse / expand the MuK apps sidebar to icons only. |
| `cst_kerama_dashboard` | Dynamic Sales / Accounting / Debts / Inventory dashboards for Kerama. |
| `cst_kerama_dispatch` | Barcode-style dispatch app: the warehouse prepares a sales order, the gate checks it line by line, the differences go back to the order. |
| `cst_kerama_finance` | Keeps the cash and bank configuration honest so the standard P&L, balance sheet and cash flow statement have a real basis. |
| `cst_kerama_full_payment` | One-click full payment from the sales order: create + post the invoice, register and confirm the payment, all linked together. |
| `cst_kerama_hr_docs` | Kadr hujjatlarini xodim kartasidan Word (.docx) qilib yaratish. |
| `cst_kerama_journal_balance` | Show what is left in every bank, cash, sale and purchase journal on the Accounting Overview card. |
| `cst_kerama_kassa` | Cash desk app: open / close / confirm the cash day, cash in and out, client payments with or without a sales order, and settling client mone |
| `cst_kerama_landed_cost` | Enter delivery, customs and other expenses straight on a receipt, bill each service provider and roll the cost into the goods. |
| `cst_kerama_no_negative` | Never let warehouse stock or a cash box go negative. |
| `cst_kerama_payment_summary` | Show Invoiced Amount, Waiting-for-approval payments (per currency) and Amount Due on the sales order. |
| `cst_kerama_payroll` | Employee salary, bonuses, fines and KPI — posted to the ledger. |
| `cst_kerama_product_display` | Show products by name and variant only - no internal reference in front of them. |
| `cst_kerama_product_price` | Mass price update from the product list: Excel template download and upload matched on barcode, prices entered in USD, and bulk +/- adjustme |
| `cst_kerama_product_search` | Mahsulotni bir necha so'z bilan, xarakteristikasi bilan qidirish. |
| `cst_kerama_project` | Make Project the hub: link sales, purchases and expenses to a project and see income (paid/due), purchases, expenses and margin on a dashboa |
| `cst_kerama_purchase_ux` | Xarid buyurtmasi: rasm, transport raqami, qabul xarajatlari; qabul sahifalari tartibi. |
| `cst_kerama_reports` | One Xisobotlar app that gathers every report the company reads — Odoo's own where they exist, purpose-built where they do not. |
| `cst_kerama_roles` | The eleven Khatdecor job roles for the Access Roles app, with their group matrix and the payroll/accounting menus hidden. |
| `cst_kerama_sale_dashboard_company` | Scope the Sales mini-dashboard amount totals to the active company |
| `cst_kerama_sale_onhand` | Sotuv buyurtma qatorida mahsulotning ombordagi haqiqiy qoldig'i. |
| `cst_kerama_sale_production` | «Ishlab chiqarishga yuborish» on the sales order: stock check of the order's products, pick what to make, and raise the orders through the s |
| `cst_kerama_sale_receipt` | Print a POS-style receipt from a confirmed sales order. |
| `cst_kerama_sale_return` | Return / refund (Qaytarish) from the sales order: credit note, refund payment and stock return back to inventory in one wizard. |
| `cst_kerama_sales_team_company` | Make the Sales Teams dashboard 'Invoicing' figure respect the active company |
| `cst_kerama_shift` | Bo'limlar, smenalar, bo'lim oynasi: buyurtmani liniyaga qo'yish, natija (1-sort / 2-sort / brak), smena yopilganda KPI fondi va jarima. |
| `cst_kerama_shopfloor` | Odoo Shop Floor operatorlar uchun: o'z stanoklari va o'z buyurtmalari, Face ID holati va ish vaqti taymeri, yangi buyurtma (texkarta, xomash |
| `cst_kerama_telegram` | Customers and suppliers read their own balance and reconciliation statement in Telegram; the company can message them back. |
| `cst_kerama_tile_m2` | Compute a tile's surface area from its height and width and sell tiles by m². |
| `cst_kerama_variants` | Ustki qismi, zichligi va o'lchami — mahsulot variantlari sifatida, 1C'dagi «характеристика» o'rnida. |
| `cst_kerama_wh_control` | Photo proof on receipts and scraps, a named receiver on internal transfers, driver and vehicle details on receipts and deliveries, and a rea |
| `cst_kerama_wh_flow` | Har bo'lim o'z omborida ishlaydi: xomashyo so'rovi, tayyor mahsulotni keyingi omborga avtomatik ko'chirish, ombor qabul qiluvchisi. |
| `cst_pos_custom_login_background` | Set custom background image for POS login screen from settings |
| `cst_show_pos_product_price` | Show product prices directly on the POS product grid for better visibility and faster selection. |
| `hikvision_attendance` | Hikvision DS-K1T320 webhook → hr.attendance, plus a Telegram bot that pushes employee check-in/out events with photos to admins. |
| `moizvonki_calls` | Calls history + recordings from Moizvonki (REST + Webhook) |
| `zxs_internal_payment_transfer` | Transfer funds between bank and cash journals with paired Send/Receive payments. |
